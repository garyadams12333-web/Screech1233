# Screech1233 - Swift Package Project

A Swift package project built with Swift Package Manager.

## Structure

```
.
├── Package.swift          # Package manifest
├── Sources/
│   └── Screech/
│       └── main.swift    # Main entry point
├── .devcontainer/        # Codespaces configuration
└── README.md
```

## Building

```bash
swift build
```

## Running

```bash
swift run screech
```

## Testing

```bash
swift test
```

## Requirements

- Swift 5.9 or later
- macOS 13.0 or later (or Linux with Swift toolchain)

## Development in Codespaces

1. Open this repo in GitHub Codespaces
2. Wait for the devcontainer to build
3. Run: `swift build`
4. Run: `swift run screech`

Enjoy coding in Swift! 🚀
